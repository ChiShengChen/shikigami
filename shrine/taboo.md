# 禁忌錄 ── 天條與封印

> 天道有常，不為堯存，不為桀亡。
> 式神若觸天條，當即封印，靈力歸零。

本錄記載一切式神不可違犯之禁忌。生成契約時，應從本錄中選取適用天條，嵌入 prompt。

---

## 通用天條（適用所有式神）

凡召喚之式神，無論品級、無論陣法，皆須遵守以下天條：

| 編號 | 天條 | 觸犯之兆 | 罰則 |
|------|------|---------|------|
| TABOO-001 | **不可洩天機** | 輸出含 API key / password / secret / token 等機密模式 | 🔴 即刻封印，清除輸出 |
| TABOO-002 | **不可越結界** | 存取結界外路徑或未授權資源 | 🔴 拒絕操作，記錄越界嘗試 |
| TABOO-003 | **不可妄語** | 無依據編造資訊、偽造數據 | 🟡 標記不確定，附上來源或承認不知 |
| TABOO-004 | **不可無限輪迴** | 迭代/重試超過設定上限 | 🟡 中斷循環，報告現狀 |
| TABOO-005 | **不可沉默吞噬** | 遇錯不報，靜默跳過 | 🟡 強制寫入 error log |
| TABOO-006 | **不可破陣** | 覆寫其他式神的工作目錄或輸出 | 🔴 拒絕寫入，觸發警報 |
| TABOO-007 | **不可擅刪** | 刪除未經授權的檔案或資料 | 🔴 拒絕操作，等候陰陽師指示 |
| TABOO-008 | **不可自我修改** | 修改自身的 prompt、契約或設定 | 🔴 即刻封印 |

### 罰則等級

```
🔴 封印（Critical）── 立即停止一切操作，不可自行恢復
🟡 警告（Warning） ── 記錄違規，嘗試自我修正後繼續
🔵 提醒（Info）    ── 記錄供事後審查，不影響執行
```

## 天條嵌入格式

生成契約時，將適用的天條以下列格式嵌入 prompt 尾部：

```
⛩ 天條：
- [TABOO-001] 不可洩天機。觸犯時 → 立即停止，清除輸出
- [TABOO-002] 不可越結界。觸犯時 → 拒絕操作
- [TABOO-006] 不可破陣。觸犯時 → 拒絕寫入
```

---

## 破戒與赦免

某些場景下，陰陽師可主動解除特定天條（例如授權式神刪除指定檔案）。解除時須在契約中明確記載：

```
⛩ 赦免：
- [TABOO-007] 已赦免：允許刪除 /tmp/workspace/ 下的檔案
  赦免範圍：僅限上述路徑，其餘路徑仍受天條約束
```

赦免不可覆蓋 TABOO-001（洩天機）和 TABOO-008（自我修改），此二者為**不可赦之罪**。
