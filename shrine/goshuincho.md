# 御朱印帳 ── 召喚日誌

> 每次召喚，皆留朱印。功過皆錄，以鑑後人。

御朱印帳記錄每一次式神召喚的軌跡。如同參拜神社後蓋下的朱印，每一筆都是陰陽師與式神之間的因緣。

---

## 御朱印格式

每次召喚完成後，記錄一筆御朱印：

```
┌─────────────────────────────────────────┐
│           ⛩ 御 朱 印 #[序號]             │
├─────────────────────────────────────────┤
│  日時  │ [YYYY-MM-DD HH:MM]             │
│  式神  │ [真名]（[英名]）                │
│  靈力  │ [★☆☆☆ / ★★☆☆ / ★★★☆ / ★★★★]  │
│  陣法  │ [陣名] 或 單體召喚              │
│  御札  │ [附加的御札列表] 或 無           │
│  使命  │ [一句話描述任務]                 │
│  天條  │ [嵌入的天條編號]                 │
│  結果  │ ✅ 成功 / ❌ 失敗 / ⚠️ 部分完成  │
│  備註  │ [選填——特殊情況記錄]             │
└─────────────────────────────────────────┘
```

## 御朱印帳統計

定期回顧御朱印帳，可統計以下指標以精進術法：

### 召喚統計
- 各式神召喚次數與成功率
- 最常使用的陣法
- 最常附加的御札

### 天條觸犯紀錄
- 哪些天條最常被觸發
- 觸犯後的處置結果
- 是否需要調整結界設定

## 使用建議

生成契約後，在回覆末尾提示陰陽師：

```
📝 此次召喚已備御朱印，是否記錄至御朱印帳？
```

陰陽師可選擇記錄或略過。御朱印帳的價值在於長期積累——召喚百次之後，方見術法精進之道。
