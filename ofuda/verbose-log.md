# 御札・千里眼 ── Verbose Log

> 千里之外，纖毫畢現。一切行動，皆入法眼。

## 效果
令式神詳細記錄每一步操作——執行了什麼命令、讀取了什麼檔案、做了什麼判斷。如同開啟天眼，一切無所遁形。適合除錯或需要完整審計軌跡的場景。

## 咒文
```
詳細記錄模式：
- 每執行一個命令前，記錄：[ACTION] 即將執行：[命令]
- 每個命令完成後，記錄：[RESULT] 結果：[摘要]（成功/失敗）
- 每次讀取檔案時，記錄：[READ] 讀取：[路徑]（[行數] 行）
- 每次寫入檔案時，記錄：[WRITE] 寫入：[路徑]（[變更摘要]）
- 每次做出判斷時，記錄：[DECIDE] 判斷：[決策內容] 原因：[簡述]
所有記錄寫入 [log path] 並同時輸出。
```

## 適用式神
- 除錯場景下的任何式神
- 首次使用新陣法時（觀察流程是否正確）
- 守護式神（安全審計需要）

## 相斥御札
- **不動明王**：千里眼產生大量操作記錄，若同時啟用不動明王（遇錯即停），可能導致記錄中斷不完整。建議二擇一，或確認不動明王僅監控核心操作而非 log 操作。
