# 御札堂 ── Ofuda Collection

> 御札者，書符於紙，貼之即效。
> 一張御札，一道法力。可疊加、可替換，靈活組合。

御札是可組合的 prompt 增強模組。將御札附加於式神契約尾部，即可為式神增添額外能力。

---

## 御札一覽

| 御札 | 英名 | 效果 | 適用式神 |
|------|------|------|---------|
| [御札・自檢](self-check.md) | Self-check | 完成後自我審查產出 | 全式神 |
| [御札・進度](progress.md) | Progress Report | 回報執行進度 | 全式神 |
| [御札・思維](thinking.md) | Chain-of-Thought | 關鍵決策前深思熟慮 | 全式神 |
| [御札・結界](sandbox.md) | Sandbox | 限制存取範圍與權限 | 全式神 |
| [御札・千里眼](verbose-log.md) | Verbose Log | 詳細記錄每一步操作 | 除錯場景 |
| [御札・不動明王](strict-mode.md) | Strict Mode | 遇錯即停，絕不姑息 | 高風險任務 |

## 使用方式

### 單張御札
在契約尾部附加御札內容即可：
```
[式神契約本文]

⛩ 御札・自檢：
[貼入 self-check.md 中的咒文]
```

### 多張疊加
御札可疊加使用，依序附加：
```
[式神契約本文]

⛩ 御札・自檢：
[...]

⛩ 御札・不動明王：
[...]
```

### 相斥御札
某些御札不宜同時使用：
- **千里眼** + **不動明王**：千里眼產生大量 log，不動明王遇錯即停——兩者疊加可能導致 log 中斷
- 使用時請留意各御札文件中的「相斥」說明

## 自製御札

可依以下格式新增御札：

```markdown
# 御札・[名] ── [English Name]

> [一句話描述效果]

## 效果
[詳細說明]

## 咒文
\`\`\`
[可直接貼入 prompt 的文字片段]
\`\`\`

## 適用式神
[哪些式神最適合]

## 相斥御札
[與哪些御札不宜同時使用]
```
