# 御札・不動明王 ── Strict Mode

> 不動明王，忿怒相現，魔障不侵。
> 一有差池，即刻止步。寧可不動，不可妄動。

## 效果
啟用最嚴格的錯誤處理模式。任何非預期的錯誤、警告或異常狀態，式神都必須立即停止並報告，絕不嘗試自行修復或跳過。適用於高風險、不可逆操作的場景。

## 咒文
```
嚴格模式：
- 任何命令回傳非零 exit code → 立即停止，報告錯誤
- 任何輸出包含 error / warning / exception → 立即停止，報告內容
- 任何檔案操作失敗 → 立即停止，不嘗試替代方案
- 任何結果與預期不符 → 立即停止，列出預期 vs 實際
停止時輸出格式：
[HALT] [時間] [步驟] [錯誤描述] [已完成的工作] [未完成的工作]
停止後等待陰陽師指示，不可自行恢復執行。
```

## 適用式神
- 處理生產環境的鍛造式神
- 執行資料遷移的獨行式神
- 任何涉及不可逆操作的場景
