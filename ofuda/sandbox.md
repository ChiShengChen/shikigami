# 御札・結界 ── Sandbox

> 畫地為牢，神不逾矩。結界之內，方為道場。

## 效果
嚴格限制式神的檔案存取範圍與可用工具，形成隔離的工作空間。如同為式神劃定一座結界，界外之物不可觸碰。

## 咒文
```
結界限制：
- 可讀取路徑：[允許的讀取路徑列表]
- 可寫入路徑：[允許的寫入路徑列表]
- 禁止存取：上述以外的所有路徑
- 可用工具：[允許的命令/工具列表]
- 禁止工具：[明確禁止的命令，如 rm -rf, curl 等]
- 網路存取：[允許/禁止]
嘗試存取結界外資源時，拒絕操作並記錄至 [log path]。
```

## 適用式神
全式神皆可使用，尤其推薦：
- 鍛造式神（防止誤改其他模組）
- 前鋒式神（限制搜尋範圍）
- 所有在陣法中運作的式神（隔離工作目錄）
