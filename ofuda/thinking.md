# 御札・思維 ── Chain-of-Thought Trigger

> 三思而後行，謀定而後動。

## 效果
令式神在關鍵決策點暫停，先以 `<thinking>` 深入分析選項，再採取行動。防止式神衝動行事。

## 咒文
```
在以下決策點，先在 <thinking> 中分析選項再行動：
- 遇到多種可能的實作方式時
- 不確定某個修改是否會產生副作用時
- 需要在速度和品質之間取捨時
- 發現與預期不符的狀況時
先列出選項與利弊，選定方案後再執行。
```

## 適用式神
全式神皆可使用，尤其推薦：
- 鍛造式神（架構決策）
- 統帥式神（調度策略）
- 審判式神（判定嚴重程度時）
